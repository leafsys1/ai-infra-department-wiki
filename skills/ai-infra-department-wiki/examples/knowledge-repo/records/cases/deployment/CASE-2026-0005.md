# 单文件页面读取产物里不存在的字段时会静默降级

## 目标
让看板展示的内容与构建产物一致：页面上出现的每一条记录、每一条关系、每一个计数，都必须来自产物
实际携带的字段，而不是页面自己假设的字段名。

## 基线
页面是单文件 HTML + 内联脚本，直接按字段名读产物：关系读 `catalog.edges`，记录卡读 `r.area` /
`r.model_family` / `r.accelerator`。而构建产物的实际情况是：`catalog.json` 没有 `edges` 键，
关系在 `graph-data.json` 里（字段 `from` / `to` / `relation_type`）；记录字段是 `areas`（列表）
与 `tags`。

## 变更变量
把页面的读取改成产物真实存在的字段：关系改读 `generated/graph-data.json` 并保留从记录关系字段
推导的兜底；卡片元信息与标签行改读 `areas` / `tags`，并把二者纳入检索字段。

## 受控与非受控变量
受控：同一份产物、同一个渲染桩、同一批断言。
未受控：真实浏览器的渲染差异——本机没有浏览器，用 DOM 桩执行页面真实内联脚本，未做跨浏览器矩阵。

## 执行步骤
1. 用 DOM 桩执行页面真实内联脚本，喂服务端实际提供的 `catalog.json` 与 `graph-data.json`。
2. 断言渲染条数 == 产物条数、图谱关系数 == 关系产物条数、卡片是否出现占位文案。
3. 冻结该检查的输出作为证据（见 `EVD-2026-0004`）。

## 结果
- 关系：`catalog.json` 无 `edges` 键，`graph-data.json` 有 16 条；页面读 `catalog.edges` 时图谱
  渲染 14 个节点、0 条关系，概览与导航的关系计数为 0，控制台无任何报错。
- 字段：页面读 `r.area`，产物字段为 `areas`；14 张卡片全部显示“未分类”，标签行为空。
- 修复后同一检查（取证时语料）：14/14 条记录、16/16 条关系、0 张卡片显示“未分类”，页面读取的字段名全部存在于
  产物中。

## 结论
页面读取产物里不存在的字段名不会报错，只会渲染空面板、0 计数或占位文案；因此“页面能打开、能渲染
出卡片”不能作为验收判据，必须把页面渲染计数与产物自身计数逐项对齐，并把“页面读了哪些字段、产物
有没有这些字段”做成可自动化的检查。

## 适用范围与风险
适用于任何“页面或报告从机器生成的产物读字段”的场景。风险：断言绑定了产物字段名，产物改名字段时
检查会失败——这正是期望行为，不要为了让它变绿而放宽断言。
