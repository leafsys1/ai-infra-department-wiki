# 权重存在性探测：api/models 与 resolve/main 的实测状态码对比

## Collection Method

对镜像站的两种 URL 形式各取样本，使用 `curl -L -s -o /dev/null -w '%{http_code}'` 记录最终状态码。
样本包含一个已确认存在的仓库、一个不存在的仓库，以及一个“仓库存在但该路径下无该文件”的仓库。

## Command

```bash
curl -sL -o /dev/null -m 25 -w '%{http_code}' <url>
```

## Relevant Output

```
200    https://hf-mirror.com/api/models/Qwen/Qwen2.5-0.5B
200    https://hf-mirror.com/api/models/THUDM/CogVideoX-5b
401    https://hf-mirror.com/api/models/definitely-not-a-real-org-xyz/not-a-real-repo
200    https://hf-mirror.com/Qwen/Qwen2.5-0.5B/resolve/main/config.json
404    https://hf-mirror.com/THUDM/CogVideoX-5b/resolve/main/config.json
404    https://hf-mirror.com/definitely-not-a-real-org-xyz/not-a-real-repo/resolve/main/config.json
```

## Interpretation

`THUDM/CogVideoX-5b` 的 `api/models` 返回 200（仓库存在），而 `resolve/main/config.json` 返回 404。
因此 `resolve` 的 404 **不能**推出仓库不存在，只能说明该路径下没有该文件。存在性判定必须使用
`api/models/<repo>`；不存在时返回 401（而非 404），也不能用“是否 404”作判据。
