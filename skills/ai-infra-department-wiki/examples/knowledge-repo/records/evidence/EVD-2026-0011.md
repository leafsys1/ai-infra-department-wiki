## 相关输出
见本记录 `locator` 指向的冻结摘录，含六节：

- 摘要与上游依据：R0027 的 79 ms 暴露、A5-only 是误收窄（`b1098db5c / #15695`）、当前 pin `f2f74a16c`（v0.26.0rc1）A2 不命中；
- 根因与判定：activation 按 TP heads 重排并 all-to-all 位于 sparse attention 与 o-proj 之间、`wo_a`/`wo_b` 分片轴不同、TP4 最小 collective 约 0.5 ms/层、6/6 正向与 7.295%；
- 决策与实现：真实入口与 A2/FLOAT 的启用条件、`wo_a` dim0 / `wo_b` dim1 的重排方式、A5 与其它量化类型不变；
- Level 3 最小验证：132 / 32 / 128 MiB、1.84–1.94 ms、1.91–1.97 ms、3.05 ms device work、每层 0.48–0.56 ms、0 mismatch、`allclose=true` 最大差 1.1444e-5；
- 冻结短服务 A/B：三个臂的逐样本 TTFT 与中位、第一组/反序组/合并的配对改善、9/9 measured 的 32768/8；

## 解释
证据支持两件事。第一，收益真实且两侧夹心可复现：三个臂顺序为 `candidate_v2 → baseline → candidate_reverse`，合并 6 对 TTFT 中位改善 7.295%、6/6 同向，total time 合并配对中位改善 7.344%；两侧 candidate 的 TTFT 中位（3.824064 / 3.865390 s）都低于 baseline（4.157885 s）。第二，机制有独立的字节与耗时支撑：activation tensor 132 MiB/rank、完整权重池 128 MiB/rank，裸 A2A 约 1.84–1.94 ms 与双 weight AG 约 1.91–1.97 ms 同阶，重叠后每层稳定节省 0.48–0.56 ms。

证据**不**支持「通信字节被消除」：摘录保留了 Level 3 仍有约 1.3–1.4 ms residual 与「本轮不宣称 TPOT 改善」两句，不得改写成通信消失或 TPOT 收益。同时摘录保留了「未跑 48×1024 正式吞吐 benchmark」，即本轮结论的边界是冻结冷 32K TTFT/prefill period。
