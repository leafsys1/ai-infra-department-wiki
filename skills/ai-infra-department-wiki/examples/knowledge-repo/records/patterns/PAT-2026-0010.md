# 局部收益不等于端到端收益：实现之前先算该链的理想上界

## Trigger Signals

单算子或子链的微基准显示明显加速（倍数或两位数百分比），但服务化正式指标不动、甚至反向。

讨论里出现「这个 kernel 快了 5 倍，值得做」这类以局部读数支撑的立项理由。

## Root Cause

完整 decode period 由许多链组成，被优化的那条链只占其中一小部分。即使把该链的开销全部消掉，端到端也只能得到「占比 × 同会话可见度」这么多。局部口径的测量不含这个结构，所以局部读数天然被放大。

## Action Pattern

实现之前先算理想上界：

- 上界 = 该链占完整周期的比例 × 同会话可见度。
- R0015：融合 kernel 在 100 个 NPU 用例逐元素正确、可削减 85–93% 的 host 链，但目标链只占 decode period 4.48%，乘同会话可见度 0.24 后期望约 0.9%。
- R0033：同条件理想单 scatter proxy 最多省 0.04042 ms/layer、0.8489 ms/full chunk，低于实现闸门约 5 倍。
- R0019：两轮反序加权 1.077× / 0.833×（方向本身不稳），最好四 chunk 上限仅 +0.240%。

上界低于闸门就不实现，把量级写清后停止；上界超过闸门才进入实现。

## Preconditions

有完整周期的时间分解（逐段计时或 op/kernel 分解），能算出被优化链的占比。

能在同一服务会话内做配对 A/B，用于估计同会话可见度，而不是跨会话比数。

## When Not To Apply

上界本身超过闸门时，这条纪律不阻止实现。同一批轮次里 R0017、R0029、R0032 都是通过的：R0029 冷 32K TTFT 配对中位改善 7.295%、R0032 改善 3.415%、R0017 是权重 kernel 口径 2.842× 且短服务配对成立。闸门不是「一律不动」，而是「先算再决定」。

整链重构、并发或拓扑调整这类改变分母的方向不属于「局部收益」，不适用本模式。

## Minimum Validation

先用同一份时间分解算出占比与同会话可见度，给出上界数字。

上界超过闸门才进入实现；实现后用同会话交错配对验证端到端。

若实现后局部变快而端到端退化，按 REVERT 归档并保留原因。

## Supporting Cases

- R0015：削减 85–93% host 链，但目标链占 decode period 4.48%、同会话可见度 0.24，期望约 0.9%。
- R0018：加权 kernel 1.169×，只省 6.635 ms/chunk = 0.709%。
- R0019：两轮反序加权 1.077× / 0.833×，最好四 chunk 上限 +0.240%。
- R0033：理想上界 0.8489 ms/full chunk，低于实现闸门约 5 倍。
- R0034：mapping 跨层复用路径成立，但 index_copy 在四个真实 shape 慢 1.52–3.77 倍；含两组 plan build 后净回归 13.005 ms/full chunk。
- R0038：8K context 生产模块单算子 bit-exact 且加速 5.55–6.07×，但冻结 1M 同会话 c12 四对 TPOT 中位 −8.12%、吞吐 4/4 负向且中位 −5.87%。
- R0007：局部 loop_ms 中位 6.5072→4.7063 ms（−27.7%）、短链路 ITL −6.47% / −6.77%，但同会话两次正式 48×1024 吞吐 511.99→482.98 / 478.84 tok/s（−5.67% / −6.47%）。
- R0022：每 decode iteration 省约 0.664 ms，但正式同会话两个有效热配对 TPOT 为 −2.39% / 0.00%，吞吐均下降。
- R0025：单算子稳定节省约 40 µs/层，但冻结短服务三轮中位 TPOT 19.1 ms 对 baseline 17.8 ms，退化 7.30%；吞吐退化 5.84%。
- R0026：一层真实 W4A8 NPU schedule 稳定改善 12.8–15.3% 且 bit-exact，但冻结短服务三轮中位 TPOT 20.3→20.2 ms，仅 0.49% 且两臂高度重叠。

## Counterexamples

R0017、R0029、R0032 是同一纪律下真正通过的轮次，说明闸门不是「一律不动」。

R0026 的局部改善 12.8–15.3% 最终只换来 0.49% 的 TPOT 改善且两臂高度重叠，属于不可分辨而非确定退化，应写「不可分辨」（见 PAT-2026-0011），不要写成回退。
