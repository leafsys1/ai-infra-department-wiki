# 判据没有判别力时，既不能写「有收益」也不能写「无收益」

## 触发信号
主指标达到预注册阈值，但输出等效、机制计数、并发档位等判别项只有部分满足。

端到端差异小于臂内噪声（重复之间的极差或 MAD）。

基线自身在同一 prompt 上重复跑不出同一输出。

## 根因
判据的分辨力（噪声地板）没有被事先标定，或该指标在当前口径下根本无法产生稳定读数。差异小于地板时，同一批数据既能被读成收益也能被读成退化，判据对结论没有约束力。

## 处理模式
两段式：

1. 单点筛查带只标「可疑」，不作结论。
2. 结论只由配对均值的置信区间或噪声倍数产生：阈值取「2×pooled MAD / 中位数控制值」，或直接要求绝对改善大于 2×pooled MAD。R0053 的噪声地板为 0.0058（组 A）/ 0.0009（组 B）；R0054 用绝对改善 655.1 ms 对 2×pooled MAD 28.5 ms。
3. 样本不够分辨力时写「未达到判定分辨力」，不写「无收益」，也不写「有收益」。

## 前置条件
判据在实验前预注册（主指标、阈值、护栏、单元数、停止判据），事后不得改写。

有同会话交错或反序配对的重复单元：R0050 预注册交错配对 A1B1A2B2A3B3A4B4A5（每臂 5 单元），R0053 每组 3 control + 3 treatment。

## 不适用场景
判据本身是布尔硬判据（bit-exact、退出码、文本逐字一致）时不需要噪声地板。

差异远大于地板时按常规 KEEP 或 REVERT 归档，不必降级为 UNVERIFIED。

## 最小验证
先算噪声地板，再看差异是地板的几倍。

报告里同时给有效单元数与无效单元数：R0050 的 armB 只有 4/5 有效单元，B5 五次尝试全挂。

## 支持案例
- R0054：中位 TTFT 2154.5→1499.4 ms（改善 30.41%），绝对改善 655.1 ms 大于 2×pooled MAD 28.5 ms，主指标达成；但配对输出等效只有 1/3 满足（seed2 不等效，A_u04 与 B_u03 输出 hash 不同，而两臂 prompt 相同、text_len 同为 708）⇒ UNVERIFIED、不记 KEEP。
- R0052：TTFT 单元中位 7.2976→2.1537 s（−70.49%），但机制项不可判定（既有 /metrics 摘录 30 行里没有该计数），且预算 280→560 与 compile 范围端点 280→560 两个量同变、归因未分离 ⇒ UNVERIFIED。
- R0059：32K×并发 8 主工作点 B 臂同窗口交错配对吞吐 +59.56% / +60.57%、TTFT −41.5% / −41.9%，D 臂吞吐 +180.11%、TTFT −70.74%，均远超同代码噪声底线 2.37% ⇒ scoped KEEP，边界同页写明（短提示不成立、EQ 工作点 TPOT 退化、精度侧 UNVERIFIED、128K 未覆盖）。
- R0058：并发 32 两次同口径运行吞吐比 8.80× 与约 9.62×，两次均 FAIL=0 ⇒ 并发 32 记 scoped KEEP；并发 8/16 仅部分成立（约 3.31× / 3.07×、5.82× / 6.49×）⇒ 不写成全域 16×。
- R0060：端到端 32K/c1 +1.05%、32K/c8 −0.87%，两处均落在臂内噪声 0.54%–1.56% 内 ⇒ 不产出端到端收益、不计为收益型 R；基线自身同 prompt 三次重复出现 2–3 种 token 序列 ⇒ 逐 token exact 判据无判别力，既不写候选 PASS 也不写候选 FAIL。
- R0050：TTFT p95 单元中位 4.67772→2.40917 s（−48.497%），pooled MAD 0.11270 s = 基线 2.409%、预注册阈值 4.818%，两条同时满足；但 armB 第 5 单元在 5 次尝试里全部挂起（0/48、0/48、1/48、10/48、1/48），「每臂 5 个有效单元」未达 ⇒ 收益 UNVERIFIED，处理臂数字建立在选择性成功子集上。
- R0049→R0050：R0049 的 −53.5% / −71.1% 与阈值 2.394% 是事后从 6 个单元子集算出的观测；同一批数据被 R0050 用预注册判据重判（9 个有效单元、−48.497%、阈值 4.818%）⇒ 性能口径以预注册口径为准。

## 反例
R0053 是「判据有判别力且未过」的正例：双组主指标均反向（−2.33% / −1.55%）且均未达预注册 >3%，长 offered-TTFT 比 1.2695 / 1.2232 双双越过 ≤10% 护栏 ⇒ REVERT。该写 REVERT 时不要用「不可分辨」软化。

R0045 是「差异小于臂内漂移」的例子：TPOT 反而 +0.126% / +0.081%，且小于同臂自身漂移（0.06–0.07 ms）⇒ 判不可分辨，既不写成收益也不写成回退。
