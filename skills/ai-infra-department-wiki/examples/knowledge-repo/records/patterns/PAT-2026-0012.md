# 机制存在性先于机制优化：能用零卡静态证据否掉的方向不要占卡去试

## Trigger Signals

想试的优化依赖一个「引擎应该有」的旋钮或开关。

上游提交看起来正好对上本地根因，但没查本地冻结配置是否允许它生效。

## Root Cause

「机制存在」「机制生效」「机制在冻结配置下生效」是三件独立的事。用加速器去试一个不存在或被静默丢弃的机制，成本是一整轮实验（含权重加载与起服）；而存在性问题通常零卡可判。

## Action Pattern

占卡之前先做零卡静态否证，五路证据示例（R0056）：

1. CLI 全量 help：`vllm serve --help=all` 1826 行，同族模式命中 0 行（落盘文件 0 字节）。
2. 配置字段全表：`SchedulerConfig` 回显逐行 20 行（来源结果文件记「21 字段」，两数并存原样保留），不含 `num_scheduler_steps`。
3. 直接传参：引擎自带 argparse 探针对 `--num-scheduler-steps` / `--multi-step` / `--num-scheduler-step` 一律 `error: unrecognized arguments`，rc=2。
4. 容器内全域 grep：`grep num_scheduler_steps` 0 命中。
5. 目标目录关键词：`vllm/v1/core/` 内 `multi_step` / `num_steps` / `n_steps` 三关键词 0 命中。

五路一致 0 命中即判「该机制在本版本没有同名入口」，不占卡。同类的另外三种静态判决：

- 显式配置被静默丢弃（R0055）：`compile_ranges_endpoints` 的显式值只是追加到派生候选集合，且必须先过守卫 `x < compile_range_end`（`compile_range_end = max_num_batched_tokens`），本部署候选值全部不小于该值 ⇒ 显式项被丢弃，5 次起服的「入参 → 生效值」全部为 None，生效端点 100% 来自派生值 ⇒ 「显式固定」这一干预设计不成立。
- 机制存在但不生效（R0057）：arm B 开启 prefix caching 后，逐字节相同的 512-token prompt 重复请求 Δqueries=+512 而 Δhits=0、Δprompt_tokens_cached=0，独立重复同样 Δqueries=512、Δhits=0 ⇒ 查询路径进入但命中链不可用。
- 机制与根因匹配但冻结配置不允许（R0037）：上游 draft ACL graph 机制与本地 host/launch 根因匹配，但冻结配置明确 `enforce_eager=true`；关闭它会改变冻结执行配置，且上游实现两天后被整体撤回 ⇒ 不实现、不占用加速器。

## Preconditions

源码或容器内文件系统可读、可 grep；CLI 可回显 help 与配置字段；冻结配置可查。

能拿到既有 /metrics 快照等只读观测，用于判断「有没有收益对象」：R0056 主体 B 的四份快照里桶 `(128,256]` 增量恒 0。

## When Not To Apply

静态证据只能否掉「机制不存在 / 不生效 / 不适用」。机制存在时的收益大小必须回到占卡实测（RUN-2026-0010）。

判决点无法本地取得（本地没有该源码、只读受限）时，先补齐取证再下结论，不能凭印象判。

## Minimum Validation

至少两路独立证据指向同一结论，单路命中不足以否证。

判决后仍要用严格表述：只读证据不支持「缺口已被触发」这类结论（R0056 主体 B 为 n=1 串行负载、未覆盖满载、桶边界无法分辨 8-token 窄带）。

## Supporting Cases

- R0056：五路 0 命中 ⇒ multi-step scheduling 旋钮不存在；四份快照桶 `(128,256]` 增量恒 0 ⇒ 补齐 decode 图捕获覆盖 248→256 没有收益对象。
- R0055：显式 compile 范围被守卫静默丢弃。
- R0057：prefix caching 查询路径进入但同串重复 Δhits=0。
- R0037：机制与根因匹配但冻结配置 `enforce_eager=true`，两天后上游整体撤回。

## Counterexamples

静态判「存在」不等于「有收益」：R0057 的查询路径确实进入，但命中计数不动。

静态证据的适用面是「存在性」，不是「成本」：R0011 / R0012 的 host 下发成本只有实测 op/kernel 分解才看得见，属于必须占卡或以既有 trace 离线复用才能得到的结论。
