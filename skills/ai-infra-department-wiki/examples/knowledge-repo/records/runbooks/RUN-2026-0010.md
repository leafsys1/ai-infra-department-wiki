# 性能实验与收益判定流程：从预注册判据到判定档

## 前置条件
基线已冻结：同模型、同量化、同并行、同负载、同预热与缓存协议。

候选改动可做成运行时开关，或能在同一服务会话内交错；跨会话比数不可用。

预注册判据在实验开始前写定并落档。

## Read-Only Checks

开始正式单元前先确认三件事，每件给「可读 / 不可读」：

```bash
# 1. 同会话 A/B 可行性：候选是否有运行时开关，或能否在同窗口交错
# 2. 护栏指标可读性：TTFT / TPOT / E2E / 失败数 / 有效输出率
# 3. 机制计数是否在低成本 /metrics 摘录里（没有该计数 ⇒ 机制项不可判定）
```

预期输出：三项各自的读数来源与路径；不可读的项先补观测，再开正式单元。

## 执行步骤
**Step 1 预注册判据**
输入：目标指标、工作负载、冻结基线。动作：写下主指标、阈值、护栏、单元数、停止判据。产出：预注册文本，事后不得改写。失败处理：无法预注册 ⇒ 本轮只记筛查或调查，不产出收益型结论。参照 R0049 与 R0050：R0049 的 −53.5% / −71.1% 与阈值 2.394% 是事后从 6 个单元子集算出的观测，同一批数据被 R0050 用预注册判据重判为 −48.497%、阈值 4.818% ⇒ 口径以预注册为准。

**Step 2 噪声地板标定**
输入：预注册判据、控制臂。动作：控制臂重复至少 3 个单元，算 `noise_floor = 2×pooled_MAD / 中位数控制值`（R0053 得 0.0058（组 A）/ 0.0009（组 B）；R0054 用 2×pooled MAD = 28.5 ms）。产出：噪声地板与最小可判差异。失败处理：地板大于目标差异 ⇒ 写「未达到判定分辨力」并停止，不写「无收益」。

**Step 3 单点筛查带**
输入：候选改动。动作：单点读数只标「可疑」，不作结论。产出：可疑清单。失败处理：把单点读数写进结论即违反 PAT-2026-0011。

**Step 4 交错或反序配对**
输入：控制臂、处理臂。动作：同会话交错（R0050 预注册 A1B1A2B2A3B3A4B4A5，每臂 5 单元；R0052、R0054 用 ABBAAB），必要时反序重复（R0019 两轮反序）。产出：配对均值加置信区间或噪声倍数。失败处理：跨会话或不同 workload 的比较 ⇒ 该数据作废，不得用于判定。

**Step 5 单元屏障与有效单元数**
输入：配对数据。动作：核对单元屏障条件（R0053 的 launch gap ≤ 0.0005 s、跨组重叠接近整段 wall），剔除无效单元（R0050 的 armB 只有 4/5 有效，B5 五次尝试全挂：0/48、0/48、1/48、10/48、1/48）。产出：有效单元数与无效原因。失败处理：有效单元不足 ⇒ 结论标注「建立在选择性成功子集上」并降级为 UNVERIFIED。

**Step 6 护栏检查**
输入：主指标结果。动作：逐项核对护栏（R0053：长 offered-TTFT 比 1.2695 / 1.2232 对 ≤10% 护栏 FAIL；吞吐比 0.9774 / 0.9854 PASS）。产出：护栏结论。失败处理：护栏越界 ⇒ REVERT，即使主指标好看。

**Step 7 判定档**
输入：主指标、护栏、判别项（输出等效、机制计数、并发档位）。动作：按 DEC-2026-0010 归档 KEEP / scoped KEEP / CONTINUE / REVERT / NOT_APPLICABLE / UNVERIFIED。产出：轮次结论与边界。失败处理：判据无判别力 ⇒ UNVERIFIED，禁止写成「无收益」。

**Step 8 结论必须写边界**
输入：判定结果。动作：写清成立范围与不成立范围（R0058：并发 32 成立、并发 8/16 仅部分成立，不写全域 16×；R0059：短提示不成立 +5.09% 且 TPOT 退化 +11.9%、EQ 类工作点 TPOT 退化 +9.2~11.1%、精度侧 UNVERIFIED、128K 未覆盖）。产出：可被下一个读者直接引用的结论行。失败处理：边界写不出 ⇒ 判定降级为 UNVERIFIED。

## 成功标准
主指标达到预注册阈值、护栏全部不越界、判别项全满足 ⇒ KEEP。

主指标达成但只在写明范围内成立 ⇒ scoped KEEP，边界与结论同页。

判据没有判别力或有效单元不足 ⇒ UNVERIFIED 或「未达到判定分辨力」。

判据有判别力但未过、或护栏越界 ⇒ REVERT。

## 失败处理
机制项在 /metrics 里没有对应计数 ⇒ 该机制项判「不可判定」，不能凭主指标反推机制（R0052）。

输出等效不满足 ⇒ 不能把指标改善归因成可复现的单旋钮优化（R0054 的 seed2 不等效）。

两个量同时变化 ⇒ 归因未分离，结论只能写「差异局限在该处」（R0052 的预算 280→560 与 compile 范围端点 280→560 同变）。

基线自身不可复现 ⇒ 该判据无判别力，既不写候选 PASS 也不写候选 FAIL（R0060 基线三次重复出现 2–3 种 token 序列）。

## 回滚
处理臂回退到控制臂配置，并回读生效值确认（PAT-2026-0018）。

恢复后做一次验证请求确认服务健康（R0054 恢复 280 后 scheduled=88、compile [280]、KV 18.05–18.06 GiB、health 16/16 加一次 2048→128 验证请求 OK）。

保留原始证据与无效单元记录，不删除失败轮次。

## 权限与安全边界
占卡、起停服务、改冻结配置需先确认授权；未授权时记录阻塞并继续其余步骤，不得把未执行写成通过。

冻结基线配置不得为「试一下」而改动；需要改冻结执行配置的方向按 NOT_APPLICABLE 归档（R0037）。
